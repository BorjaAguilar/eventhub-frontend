# EventHub Frontend

Interfaz web de EventHub, una plataforma para descubrir, reservar y gestionar
eventos. Está construida con React y Vite.

## Desarrollo local

```bash
npm install
npm run dev
```

Vite mostrará en la terminal la dirección local de la aplicación.

## Variables de entorno

Copia `.env.example` como `.env` para personalizar la dirección de la API:

```text
VITE_API_URL=https://eventhub-backend-diw3.onrender.com/api
```

Los nombres que se utilizan desde el navegador deben comenzar por `VITE_`.
